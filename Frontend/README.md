# خشبي | WOODEN — الواجهة الأمامية

موقع تعريفي (فرونت إند فقط) مبني بـ **React + Vite + Tailwind CSS v4**.
كل أزرار التواصل تفتح نفس رقم الواتساب/الهاتف المعرّف في ملف واحد.

## التشغيل

```bash
npm install     # مرة واحدة فقط
npm run dev     # تشغيل محلي على http://localhost:5173
npm run build   # إنتاج الملفات النهائية في مجلد dist/
npm run preview # معاينة نسخة الإنتاج
```

    ├── App.jsx                 ← يجمّع الأقسام ويدير نافذة الاستشارة

    ├── data/
    │   └── content.js          ← كل النصوص: المشاريع، المواصفات الفنية، الآراء، الأسئلة، الحاسبة
    │
    ├── components/             ← عناصر مشتركة
    │   ├── Navbar.jsx          ← شريط التنقل + قائمة الجوال
    │   ├── Footer.jsx          ← التذييل + بطاقة CTA
    │   ├── FloatingActions.jsx ← الأزرار العائمة (استشارة / اتصال / واتساب)
    │   ├── ConsultationModal.jsx ← نافذة طلب الاستشارة → واتساب أو اتصال

    └── sections/               ← أقسام الصفحة الرئيسية بالترتيب
        ├── Hero.jsx            ← الواجهة الرئيسية

## تغيير رقم الواتساب

افتح `src/config/contact.js` وغيّر السطر:

```js
const WHATSAPP_NUMBER = "966542055042"; // بدون + وبدون مسافات
```

وغيّر `phoneDisplay` للرقم الذي يظهر للزائر. كل الأزرار (الهيدر، الهيرو، الباقات،
المعرض، الحاسبة، نافذة الاستشارة، الأزرار العائمة، التذييل) ستتحدث تلقائياً.

## تغيير النصوص أو الصور

- النصوص: `src/data/content.js`
- الصور: ضع الصورة في `public/images/` ثم حدّث المسار في `IMAGES` داخل `content.js`
